The files avaspec.py and avaspec_fix_winfunctype.py are a Python ctypes wrapper
around avaspecx64.dll, the proprietary spectrometer library distributed by Avantes
BV with the AvaSpec-DLL SDK. The wrapper follows the structure, the function
signatures and the constant names of the Python example that Avantes ships with that
SDK, and is therefore treated here as derived from it rather than as original code
under the GNU GPL.
